# Iran–Israel War Sentiment Analysis

This project analyzes tweets related to the Iran–Israel conflict using Machine Learning and Natural Language Processing (NLP).

## Technologies Used
- Python
- Pandas
- NLTK
- Scikit-learn
- TF-IDF
- Logistic Regression
- Random Forest

## Project Steps
1. Data Cleaning
2. Text Preprocessing
3. TF-IDF Feature Extraction
4. Train-Test Split
5. Model Training
6. Model Evaluation

## Results
The model classifies tweets into:
- Positive
- Negative
- Neutral

Random Forest achieved better accuracy compared to Logistic Regression.
